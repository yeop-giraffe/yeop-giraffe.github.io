Overview

Indoor UAV operators must navigate narrow passages and obstacles through a limited camera view. This thesis asks whether intuitive control mapping and spatial visual cues can make teleoperation easier for novice operators.

This master's thesis investigates both sides of that interaction: an intuitive controller mapping and a monocular-vision interface that supports spatial awareness. The interface combines three-dimensional scene reconstruction, nearby-obstacle highlighting, and predicted flight-path visualization. A physical prototype checks system integration, while separate Gazebo studies evaluate the controller and interface with novice operators.

Related work is presented in the ICROS indoor UAV navigation papers. This thesis focuses on controller design, the integrated display, and user evaluation.

Intuitive Flight Control

The controller design takes inspiration from helicopter controls, separating horizontal motion, altitude, and heading. A Logitech Extreme 3D joystick uses forward/backward and lateral hand movement for horizontal flight, a lever for altitude, and wrist rotation for yaw. A button triggers image capture, and a dead zone suppresses unintended commands around the neutral position.

Commands are interpreted relative to the UAV's forward direction using its current attitude. This keeps the operator's input aligned with the view transmitted by the forward-facing camera.

From a Camera View to Spatial Awareness

Reconstructing the Surrounding Space

Monocular depth estimation predicts relative depth from the forward RGB image, while ORB-SLAM3 provides sparse feature points and camera motion. Least-squares fitting aligns the predicted depth with SLAM feature depths. A second calibration compares SLAM motion with visual-inertial position estimates to recover metric scale, smoothing the scale estimate with a moving average. The calibrated points are combined in a shared coordinate frame to reconstruct the scene.

The forward-view reconstruction uses a monocular RGB camera. A separate visual-inertial tracking camera provides vehicle position and scale information.

Highlighting Nearby Obstacles

U- and V-disparity histograms distinguish obstacles from the floor. Morphological closing cleans the segmentation, and an operator-selected metric-depth threshold filters the display to nearby obstacles. The operator sees the relevant obstacle regions overlaid in red on the original camera stream.

Showing the Intended Flight Path

Controller input, vehicle position, and attitude are used to predict and display the flight direction. A perspective path overlay changes with forward motion and turns. The final interface adds a 3D scene inset and vehicle-position readout to the camera view, helping the operator interpret the scene and the commanded motion together.

Physical Prototype & Integration Checks

The remotely operated UAV carries a monocular RGB camera and an NVIDIA Jetson Nano embedded computer. ROS-based communication supports remote control and data exchange with the operator station.

Indoor tests checked positioning, joystick-based remote flight, video transmission, and the generated assistance display. Across eight repeated positioning tests, the thesis reports distance errors of 5.25% in the x direction and 3.21% in the y direction relative to the start position. These checks establish prototype operation; the participant comparisons below were performed in simulation.

Two Separate User Evaluations

Each evaluation involved six adults in their twenties with no prior drone-control experience (four men and two women). Both were conducted in Gazebo. The controller study held the interface constant; the interface study held the controller constant.

Controller Comparison

Participants flew a seven-gate course in a 25 × 25 m area using the proposed joystick mapping and a gamepad. The 1.4 × 1.4 m gates spanned 3 m in altitude. After one minute of practice, each participant completed one run per controller with the same RGB display. Recorded trajectories were compared for path smoothness and distance to gate centers.

Interface Comparison

Participants searched for four people in a simulated factory using the assisted interface and RGB video alone. Each completed one flight per interface with the same controller. Post-flight questionnaires measured usability with the System Usability Scale (SUS) and perceived workload with six NASA-TLX subscales.

Interface: Higher Usability, Lower Reported Workload

System Usability Scale (SUS) scores improved by 28%, from 62.5 to 80. NASA-TLX mental demand decreased by 43%, from 57.5 to 32.5. The other five subscales also decreased; the 43% figure refers specifically to mental demand.

Controller: Smoother, More Centered Flight

The proposed mapping produced a lower path-smoothness score, which represents less unnecessary motion, and a smaller distance to gate centers. These metrics describe the recorded simulated trajectories, rather than a measured disaster-mission success rate.

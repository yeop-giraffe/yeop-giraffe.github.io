DART: From Attentive Reasoning to Intuitive Execution for Experience-Driven Robot Intelligence

Abstract

Humans rely on both intuitive and deliberate processing, as described by dual-process theories of cognition: novel tasks often require effortful reasoning, whereas accumulated experience allows similar tasks to be handled more automatically and with less cognitive effort. Motivated by this principle, we propose DART (Deliberation-Adaptive Reasoning from Task Experience), which applies the same principle to robots through two connected modes.

When the robot lacks sufficient task-relevant knowledge or prior experience, it operates in Attentive Mode, performing high-level reasoning and acquiring the additional knowledge needed for the task. The newly acquired knowledge is stored in a persistent scene graph and accumulated across tasks. As experience builds, the robot increasingly operates in Intuitive Mode, reusing this knowledge for later related tasks without repeated high-level reasoning.

We evaluate DART in simulated and real-world environments, including deployment on a resource-constrained platform, and show that as knowledge accumulates in the scene graph, the robot requires less high-level reasoning and less additional information gathering while maintaining task performance.

From Reasoning to Reuse

A home robot repeatedly encounters related requests in the same environment. A map built beforehand can miss the knowledge a task needs, while repeated high-capacity model inference adds computational cost. DART acquires knowledge when it becomes necessary and retains it across tasks, without updating neural-network parameters during execution.

Lightweight Scene Construction

A 2D LiDAR occupancy map and on-device, closed-vocabulary YOLOv8 detections provide the starting representation. Geometric region segmentation, object-based region classification, multi-view object mapping, and observation viewpoints selected for visibility and accessibility are assembled into a compact graph after mapping. Initial object mapping assumes floor-supported targets and estimates their 2D locations and planar extents from image contours and depth measurements.

Interaction Layer

An LLM parses natural-language instructions into task fields aligned with the graph hierarchy. This structured representation is passed to Intuitive Mode for knowledge retrieval and execution.

Intuitive Mode

Search the persistent graph for relevant spatial information, functional relations, and execution procedures. Execute directly when that knowledge is sufficient. This mode does not invoke an LLM; unresolved knowledge gaps are passed to Attentive Mode.

Attentive Mode

Use LLM reasoning and targeted VLM observations from stored viewpoints to acquire missing task knowledge. Execute the task, then integrate the acquired descriptions, relations, and procedures into the graph for later reuse.

Experimental Setup

Each environment contains 20 object-search and navigation tasks. The full sequence is repeated for five iterations, retaining task-acquired knowledge across tasks and iterations. DART-Frozen is the comparison baseline: it also acquires information for the current task, but discards that information after execution.

Each task starts from the same pose in front of the docking station and is limited to 20 VLM calls. Task success is assessed from execution logs and final responses against the instruction. A separate single-task experiment repeats each of the 20 tasks ten times, retaining acquired knowledge within those ten repetitions and restoring the initial graph before moving to the next task.

Physical platform
Commercial robot vacuum cleaner with 2D LiDAR, an RGB camera, and a short-range depth camera; in-house SLAM and grid-based navigation.
Simulation
NVIDIA Isaac Sim 5.1.0, Cartographer, and ROS 2 Nav2.
Perception
YOLOv8 retrained for household objects observed near floor level.
Reasoning
Qwen3.5 for task parsing, text-based reasoning, and visual semantic acquisition; inference runs on an external server.
Memory
Persistent scene graph with geometric, semantic, and functional task knowledge.

My Contributions

As a co-first author, my contributions focused on the architecture, lightweight spatial perception, and system integration:

  • Contributed to the dual-process architecture for task-knowledge reuse and incremental scene-graph enrichment.
  • Developed observation-viewpoint selection based on object visibility and viewpoint accessibility.
  • Developed room classification using object occurrence likelihoods and visual evidence accumulated during robot navigation.
  • Integrated VLM, perception, and navigation modules into the Spatial AI system and validated the system in NVIDIA Isaac Sim.

Scope & Future Work

This study considers repeated tasks in the same or slowly changing environment, using a resource-constrained mobile platform. Evaluation covers object search and navigation in two residential environments; it does not establish manipulation performance or long-term robustness across diverse homes.

Future work will extend the framework to platforms with manipulation capabilities, add temporal information to track changes in object states and spatial relations, and evaluate long-term deployment across more environments and users.
